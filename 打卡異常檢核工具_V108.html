📖 說明書：全部異常樣態怎麼判定

共 8 個樣態（時間性 5、衛星訊號 1、空間性 2）。點標題展開／收合；資料只在瀏覽器內計算，說明依本工具現行的判定邏輯整理。計數單位：樣態用「項」、工作規劃用「筆」。
前言
  • 判定規則與「督導管理系統」儀表板的異常打卡檢核一致；本工具在同一套判定之上，另外提供可調的門檻（每人容許項數、兩段門檻與備查）。各卡片門檻全填 0 時，結果與儀表板相同。
  • 本說明書的「正面表列」＝納入條件、「負面表列」＝排除條件。
  • 通路別不參與八個異常樣態的判定，僅「逾四小時」有一項例外：量販通路、即飲通路，或處所（店家型態屬其他類別、店名含營業處／營業所／商化所；店名含「臨時」者除外）者改列「四小時備查」，不列為異常（見第三節、第八節）。
  • 計數單位：以樣態計算的數字用「項」（樣態卡片、樣態合計、各樣態欄、排除與備查門檻、明細的總數）；以工作規劃（一次拜訪＝一筆打卡）計算的數字用「筆」（打卡筆數、異常打卡筆數、異常打卡率）。一筆打卡可以有多項異常；例如同一次拜訪的到站、離站都偏移，樣態算 2 項，異常打卡筆數只算 1 筆（見第十節、第十一節）。
  • 前六個樣態只需要工作規劃；「定位偏移」「臨時點異地離站」另需要打卡異常報表。

六、空間性：定位偏移／臨時點異地離站

空間性有兩種「不同」的情形，來源都是打卡異常報表，需通過共同門檻 B。

7-1　定位偏移：一般店家，打卡 GPS 離店家登記地址太遠。

納入正面表列

  • 報表「錯誤距離」（單位：公里）≥ 門檻；畫面可調，預設 0.5 公里，填 0＝報表的列全收
  • 到站、離站兩種類型的列都會檢查，兩者是不同的情形：到站偏移、離站偏移各算 1 項（兩者同屬「定位偏移」卡片，不合併）
  • 每一列依「人員＋打卡時間（與工作規劃的到站或離站時間相差 1 秒內）」對回工作規劃的那一次拜訪；對不回者整列排除。異常打卡筆數就是以這個對回的拜訪為單位計算

排除負面表列

  • 店名含「臨時」（臨時點沒有登記地址）
  • 店家型態為「室內點」「室外點」（型態取自工作規劃含「型態」的欄；查不到型態資料時不排除）
  • 沒有「錯誤距離」數值的列

7-2　臨時點異地離站：同一次拜訪臨時點，到站 GPS 與離站 GPS 不在同一處。

納入正面表列

  • 店名含「臨時」
  • 同一次拜訪（到站列與離站列都對回同一筆工作規劃），兩者都有 GPS 座標
  • 兩點直線距離（本工具自行計算）≥ 門檻；畫面可調，預設 0.5 公里；標在離站那一列

排除負面表列

  • 非臨時店（一般店家不算，交給定位偏移）
  • 只有到站沒有離站、或任一邊沒有 GPS

7-3　兩種空間性樣態的三階段處理：定位偏移與臨時點異地離站各自獨立設兩個門檻（卡片內「≤ N1 排除　＞ N2 異常」；預設定位偏移 10／30、臨時點異地離站 5／15）。以每人在該樣態的項數判定（到站偏移與離站偏移合併計入「定位偏移」項數）：≤ N1 排除；超過 N1 且不超過 N2 列「備查」（未列入異常統計，見第八節）；超過 N2 才列異常。

七、對象與通路別
項目取法
人員「業務員」（含員編）；畫面只顯示姓名，匯出一律保留員編
營業處「營業處」欄，去掉「營業處」字尾
營業所／課（工作規劃來源的六個樣態）使用者檔 → 客戶資料檔（同一人多個所時取筆數最多者）→ 都沒有就歸「其他」
營業所／課（打卡異常來源的兩個樣態）打卡異常報表自帶 → 使用者檔 → 客戶資料檔 → 「其他」
匯出對象樹營業處 → 營業所 → 人員；份數可選整份、一處一份、一所一份、一人一份

通路別

  • 八個樣態的判定，除「逾四小時」外沒有通路別的判斷；「逾四小時」於量販通路、即飲通路、處所（店家型態屬其他類別、店名含營業處／營業所／商化所，店名含臨時者除外）者改列四小時備查（見第八節）。
  • 通路別只出現在「客戶資料」下載視窗：傳統通路、即飲通路、室內外點、菸酒專、CVS通路、連鎖超市通路、量販通路、其他類別（預設勾選除「室內外點」以外的七類）。
  • 客戶資料主要用來補「人員 → 營業所／課」對照，另外提供顯示用的通路別（依店家代碼對回，只用於逐筆明細、備查明細、店家排行的「通路別」欄，不影響任何判定）；所以通路勾選不同，只可能影響某人被歸在哪個營業所，不會改變任何樣態的筆數（四小時備查的認定取自工作規劃本身的通路別、店家型態或店名，與客戶資料無關）。
八、備查

定義：通路別為量販通路、即飲通路，或處所（店家型態屬其他類別，且店名含營業處、營業所、商化所，不含「臨時」）者，且停留 ≥ 4 小時（與「逾四小時」同門檻）的工作規劃紀錄。這類紀錄不列為異常，另放「四小時備查」供大家檢視。

納入正面表列

  • 通過共同門檻 A、「工作完成日期」有值、停留大於或等於 4 小時
  • 通路別認定（依序）：①工作規劃含「通路」欄、且該列有值 → 值含「量販」或「即飲」才算；②沒有通路欄、或該列空白 → 改看「店家型態」，為家樂福量販店、愛買、大全聯、即飲通路者才算；③店家型態屬其他類別、且店名含「營業處」「營業所」「商化所」者（處所），不看通路別，一律算；但店名含「臨時」者視為臨時點，不算（例：「台中營業處-臨時點」「臨時點-臺南營業處」仍列逾四小時異常）

不計入與異常統計的關係

  • 四小時備查不計入樣態合計（項）、異常打卡筆數（筆）、異常打卡率；也不影響打卡筆數（分母）。
  • 這類紀錄不會同時出現在「逾四小時」異常；其餘樣態（例如同一筆同時有「時間重疊」）照常判定。
  • 四小時備查卡內有自己的「≤ N 項排除」：某人員的四小時備查項數 ≤ N 就不顯示（預設 5；填 0＝全顯示）；畫面、備查檢視、Excel 分頁、匯出報表一致。不受異常樣態的各樣態排除值影響。

呈現位置

  • 畫面：異常卡片旁有虛線的「🗂 備查」群組，內有「四小時備查」卡片，點擊切換至備查檢視（受營業處、營業所、搜尋篩選），再點一次回人員彙總；另有「備查」按鈕（看全部備查；先列備查人員彙總，再列明細）。
  • 匯出 Excel：新增「備查人員彙總」「備查明細」兩個分頁。
  • 匯出報表（PDF／靜態 HTML）：於「附表」前新增「四小時備查」；匯出視窗可勾選是否含備查，備查段先列備查人員彙總，再列備查明細。對象樹也會列出「只有四小時備查」的人員（可勾選、可一人一份）；這類人不出現在人員彙總（彙總只算有異常的人），只出現在備查段。

備查的三種類別與人員彙總

  • 四小時備查（上述）、定位偏移備查、臨時點異地離站備查（第九節的兩段門檻：N1 ＜ 項數 ≤ N2）。三類都不計入異常統計。
  • 備查檢視、匯出報表的備查段、Excel 的「備查人員彙總」分頁，都會先列人員彙總（每人各類備查項數、備查合計、涉及店數），再列備查明細。點畫面上的備查卡片只看該類，按工具列「備查」看全部。在備查人員彙總點某位人員，可只看該人的備查明細，按「← 返回備查人員彙總」（或 Esc）回到彙總。
  • 備查明細有「備查類別」欄；匯出時，定位偏移備查、臨時點異地離站備查跟著④勾選的樣態走。
九、判定後的「顯示排除」

這一項不是異常判定本身，而是決定「要不要顯示這個人的這個樣態」。

設定預設規則
各樣態排除值（卡片內「≤ N 項排除」）不足一分 10、逾四小時 5、時間重疊 10、隔三小時 5、同店連打 10；四小時備查 5；衛星訊號異常 0（全部顯示）；定位偏移、臨時點異地離站另有兩段門檻，見下一列某人員在某個樣態的項數 ≤ N，就不顯示該人員的該樣態；填 0（或留白）＝全部顯示
定位偏移、臨時點異地離站的兩段門檻（卡片內「≤ N1 排除　＞ N2 異常」，兩者各自獨立設定）定位偏移 N1＝10、N2＝30；臨時點異地離站 N1＝5、N2＝15以「每人、每個樣態」的項數判定：項數 ≤ N1＝排除（不顯示）；N1 ＜ 項數 ≤ N2＝列「備查」（未列入異常統計）；項數 ＞ N2＝列異常。N2 不大於 N1 時沒有備查區間（超過 N1 就是異常）
  • 被隱藏的項、列為備查的項，都不計入「樣態合計」與「異常打卡筆數」，但分母「打卡筆數」不變。
  • 畫面上的營業處、營業所、業務員、搜尋只影響畫面；匯出報表使用全部結果，內容由匯出視窗的「異常樣態」與「對象」勾選決定。
十、統計欄位怎麼算（項與筆）

兩種單位：以樣態計算＝「項」；以工作規劃（一次拜訪）計算＝「筆」。

欄位單位算法
各樣態欄（含卡片）項該人員在該樣態被判為異常的項數。定位偏移的到站偏移、離站偏移各算 1 項；套用排除值（≤ N 項排除）與兩段門檻之後才顯示
樣態合計項該人員各樣態項數相加。一筆打卡同時命中兩個樣態（或到站、離站都偏移）算兩項，用來看「有多異常」
打卡筆數筆該人員通過共同門檻 A 的工作規劃筆數（分母）
異常打卡筆數筆有任一樣態的不重複拜訪筆數：一筆打卡不論命中幾項只算 1 筆（看有幾筆被標出異常）。打卡異常來源的樣態（定位偏移、臨時點異地離站）依打卡時間對回同一次拜訪的工作規劃列；同店同日去多次，每次各算一筆；同名但店碼不同的店也各算各的。異常打卡筆數一定 ≤ 樣態合計
異常打卡率—異常打卡筆數 ÷ 打卡筆數
備查項數項僅畫面的人員彙總顯示（灰色）：該人的備查項數，未計入上列任何統計
  • 備查項數可點：直接看該人的備查明細，按「← 返回人員彙總」回來。只有備查項的人員，會以灰底列在人員彙總最下方（未選樣態卡片時），點該列直接看其備查明細。
  • 從人員彙總點人員進逐筆明細時，若此人另有備查，工具列會出現「此人另有 N 項備查 → 查看」。
  • 逐筆明細、備查明細的列數，單位也是「項」（一列＝一項異常或備查）。

業務員「王小明-12345」某日工作規劃（皆為已讀、完成、有店碼）：

範例二：一筆打卡到站、離站都偏移。業務員某日到「台東店」拜訪 1 次，打卡異常報表有兩列：到站打卡距登記地址 1.2 公里、離站打卡距登記地址 1.3 公里（皆 ≥ 0.5 公里門檻）。兩列都對回同一筆工作規劃：

十二、店家排行（不分人員）

看「哪些店家最常發生異常樣態」，不分人員。按主畫面的「店家排行」進入。

  • 以店家代碼為單位彙總；同一店碼名稱不同時，顯示出現最多的店名。
  • 欄位：店家型態、通路別、各樣態項數、樣態合計（各樣態項數相加，單位項）、異常打卡筆數（不重複拜訪，單位筆）、涉及人數（該店發生異常的不同人員）、打卡筆數（該店納入稽核的工作規劃筆數，單位筆）、異常打卡率＝異常打卡筆數 ÷ 打卡筆數。
  • 表頭分兩層：「異常樣態（單位：項）」＝各樣態與樣態合計，「打卡統計（單位：筆）」＝打卡筆數、異常打卡筆數、異常打卡率，最右為涉及人數；人員彙總的最右則是備查項數。
  • 預設依樣態合計大→小；點表頭可改排序（再點一次反向）；點店家列可看該店逐筆明細。
  • 受營業處、營業所、業務員、搜尋與上方樣態卡片篩選；已套用各樣態「≤ N 項排除」（排除是以「人員＋樣態」判定，所以被隱藏的項不會計入店家）。四小時備查不計入。
  • 畫面最多顯示前 500 家；匯出 Excel 的「店家排行」分頁含全部。
十三、原始資料查詢（複驗用）

逐列列出載入的「工作規劃」與「打卡異常」原始資料，並標示每一列被工具怎麼處理，方便拿原始檔與產出結果對帳。按主畫面的「原始資料」進入；匯入了幾種資料就有幾個小頁籤（工作規劃、打卡異常、人員／客戶資料），各自獨立檢視。

判定意義
未納入沒通過共同門檻，列出原因（依序取第一個符合者）。工作規劃：非員編後綴、無店家代碼、無到站打卡時間、總公司；打卡異常：非員編後綴、打卡時間無法解析、總公司、日期不在工作規劃區間、無到站打卡（對不回工作管理）
納入・未命中樣態納入稽核（計入打卡筆數）但沒命中任何樣態；工作規劃列顯示停留時間，打卡異常列顯示錯誤距離
有異常命中一個以上樣態，說明欄列出每個樣態與判定依據（含同一次拜訪對回的定位偏移、臨時點異地離站）
有異常（排除值隱藏）命中樣態，但該人員該樣態項數 ≤「≤ N 項排除」而未顯示於統計
備查四小時備查（量販／即飲通路、營業處／營業所／商化所逾四小時）、定位偏移備查、臨時點異地離站備查；皆未列入異常統計
  • 「人員／客戶資料」小頁籤：逐列顯示對照檔的原始列，標示是否被採用為營業所/課對照（使用者檔優先，其次客戶資料檔中該人筆數最多者），未採用者列出原因。
  • 上方對帳統計：各來源「納入＋未納入＝總列數」，並列出未納入的原因分布。
  • 點任一列可展開該筆的全部原始欄位；說明欄的「被引用為……之前筆／到站配對」表示這列本身未命中樣態，但被其他筆的間距類或臨時點判定當作比對對象。
  • 受營業處、營業所、業務員、搜尋篩選；畫面最多 1500 列；匯出 Excel 時需在匯出視窗勾選「含原始資料分頁」才會附上，依小頁籤各一個分頁（原始查詢_工作規劃／打卡異常／人員客戶）含全部。
十四、匯出怎麼用

按工具列「匯出」開啟對話框，由上而下依序設定：

步驟說明
① 檔案格式PDF、靜態 HTML（用瀏覽器開啟，可直接列印）、Excel，三選一
② 份數整份、一處一份、一所一份、一人一份；依⑤所選的對象切分，多份會自動打包成 ZIP
③ 人員彙總排序（選填）可依樣態合計、打卡筆數、異常打卡筆數、異常打卡率、人員姓名排序，並選大→小或小→大；只影響人員彙總表。不選＝預設（營業處 → 營業所 → 樣態合計）
④ 異常樣態勾選要放進匯出檔的樣態，預設帶入主畫面已選的樣態卡片（沒選＝全部）。人員彙總欄位、逐筆明細、小卡與對象的項數都只算勾選的樣態；篩完沒有項數的人員不會產生報告。可另勾選是否含備查、含原始資料分頁（原始資料分頁僅 Excel 使用）
⑤ 對象點營業處、營業所／課看下一層，勾選要匯出的人員，勾選框可整批勾選；也有「全選對象」「全不選對象」。匯出不受主畫面的營業處、營業所、業務員、搜尋篩選影響，一律使用全部結果
⑥ 確認核對統計數字，無誤後按「匯出」

PDF／靜態 HTML 報表的內容

  • 人員彙總自成一頁：樣態合計（項）、打卡筆數（筆）、異常打卡筆數（筆）、異常打卡率；預設排序下會加「小計」，最後加「總計」；匯出對象只有一人時，只列該人一列，不另加總計。
  • 逐筆明細以營業處為單位換頁；匯出含多個營業處時，每個營業處的明細第一頁上方會先附該處的人員彙總。逐筆明細帶「通路別」「店家型態」兩欄，方便判讀是哪一類店：通路別優先取工作規劃「通路」欄，工作規劃沒有時依店家代碼對回客戶資料（③）的通路欄（打卡異常來源的列同樣依店碼對回），處所（店家型態屬其他類別、店名含營業處／營業所／商化所）標「處所」，查無資料則空白。
  • 備查（有勾選時）：放在附表之前，先有「備查人員彙總」再列備查明細，內容見第八節。
  • 每張樣態小卡會標示「≤ N 項排除」（N 為該樣態目前的排除值，0＝全顯示）。
  • PDF 內的文字可選取、搜尋；預估超過 150 頁時會先詢問是否繼續。

最後一頁：附表「異常樣態判定標準」（僅 PDF／靜態 HTML，Excel 沒有）

  • 三欄：樣態名稱、列入異常之條件、不列入之例外情形；末段另列「計數單位」說明項與筆的差別。
  • 只列出④有勾選的樣態，另加一列「各樣態共同適用」（納入稽核與不納入稽核的對象）；有勾選含四小時備查時，會多一列「四小時備查」。
  • 定位偏移、臨時點異地離站的公里數，取畫面上目前設定的門檻；衛星訊號異常的店名排除固定為處所與臨時點。

Excel 的分頁：預設 5 個結果分頁——人員彙總（第一頁）、異常明細、店家排行、備查人員彙總、備查明細；勾選「含原始資料分頁」才會再附上原始查詢分頁（見第十三節）。

十五、畫面操作：業務員篩選、返回、截圖
  • 業務員篩選：工具列「篩選」群組的「業務員」欄，可從下拉選單挑，也可直接輸入姓名；選項會隨所選的營業處、營業所／課連動；清空＝全部。它和營業處、營業所、搜尋一起作用於人員彙總、逐筆明細、店家排行、四小時備查、原始資料，不影響匯出。
  • ← 返回：從人員彙總或店家排行點某一列進入逐筆明細後，工具列會出現醒目的「← 返回人員彙總」或「← 返回店家排行」鈕，按 Esc 鍵效果相同；返回時會還原進入前的搜尋字串。
  • 表頭分組：人員彙總與店家排行的表頭分兩層，上層標出「異常樣態（單位：項）」「打卡統計（單位：筆）」，兩組之間有粗分隔線與不同底色；匯出的 PDF、HTML、Excel 同樣分組（Excel 首列為合併的分組列，自動篩選從第二列開始）。
  • 單位用詞：樣態卡片、群組合計、各樣態欄、樣態合計、「≤ N 項排除」、「備查 11～20 項／人」、備查項數、「此人另有 N 項備查」、逐筆明細與備查明細的總數，一律用「項」；打卡筆數、異常打卡筆數、工作規劃列數用「筆」。滑鼠移到表頭或卡片上會顯示該欄算法。
  • 🧩 快照：匯出診斷用 JSON（設定、人員彙總含不重複拜訪數、異常與備查明細、重點人員的工作規劃與打卡異常原始列），只存在本機；在搜尋人員欄選定某人再按，就以此人為重點。
  • 📸 截圖：把主畫面目前顯示的內容（包含完整表格）轉成圖片複製到剪貼簿，可直接貼到簡報或訊息；若瀏覽器不允許寫入剪貼簿，會改存成 PNG 檔。表格很長時畫質會自動縮小，建議先篩選縮小範圍。截圖元件需連網載入。
